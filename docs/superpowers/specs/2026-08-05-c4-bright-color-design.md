# C4 明亮高彩色彩调整设计

状态：用户确认（2026-08-05）

## 1. 目标

在不改变熊猫析题现有构图、信息层级和交互行为的前提下，消除当前界面偏灰、偏雾的观感。最终方向为「C4 · 明亮高彩晨光」：

- 绿色更鲜明、更有生命力；
- 原棕金色统一向明亮的向日葵黄偏移；
- 紫色降低饱和度但提高明度，成为通透的薰衣草辅助光；
- 中央题目与对话阅读面继续保持暖白，不能被大面积高彩色覆盖。

此次调整是现有「专注光场 · 明亮中庭」视觉世界的色彩增强，不是新一轮布局重做。

## 2. 范围与非目标

### 2.1 调整范围

- 根页面环境光场、壳层和侧翼色彩；
- 主绿色阶、选中态、焦点态和主要操作色；
- 文件夹、题目卡和问题卡中的棕金色；
- 四组知识卡主题和一组题目卡主题；
- 与上述颜色直接相关的边线、柔影和浅色表面；
- `DESIGN.md` 中的色彩令牌与卡片主题记录；
- 色彩合同测试与最终多尺寸截图。

### 2.2 明确不调整

- 顶栏、左栏、中央舞台、右栏的尺寸和构图；
- 左侧「试卷 → 题目」层级及所有恢复、搜索、展开、删除能力；
- 右侧卡片库、文件夹、筛选、保存、移动、导出和清空能力；
- 右缘竖向卡签的数量、顺序、筛选、`66 × 128px` 几何和 `-28px` 重叠；
- 卡片 `idle → preparing → opening → open → closing → idle` 状态机；
- `480ms` 打开、`440ms` 关闭及来源矩形往返路径；
- 正反翻面、正反字段映射、打开后的焦点进入与关闭后的焦点归还；
- 响应式断点、安全区、reduced-motion 以及任何 API/数据结构。

不增加熊猫、插画、贴纸、渐变文字或 mock-only 控件。

### 3.2 环境光场

`body` 的三层背景目标为：

```css
radial-gradient(circle at 6% 2%, rgba(105, 204, 105, 0.68), transparent 38%),
radial-gradient(circle at 96% 100%, rgba(183, 168, 212, 0.58), transparent 40%),
linear-gradient(122deg, #c6edc3 0%, #fffce9 51%, #eae4f5 100%)
```

绿色与紫色只存在于壳层外围、侧翼透光和轻量装饰中。`.conversationPanel`、`.messageViewport`、正文消息和输入器的主要阅读表面继续使用暖白或接近暖白的透明表面。

### 3.4 直接色值的收敛

仅收敛与本次方向直接相关的旧灰绿和棕金色：

- 左栏 active、品牌按钮、焦点环使用新的绿色阶；
- 卡片库文件夹由米棕表面改为 `--stage-yellow-soft` 系列；
- 问题卡标签、文件夹图标和题目卡点缀使用 `--stage-yellow`；
- 紫色背景光与紫色卡签分别使用 soft / deep 层级；
- 壳层、侧翼和输入器提高暖白透明度，去除脏灰感。

错误、危险、成功、信息等业务状态不能因为追求统一而改成绿色、黄色或紫色；深色图像查看器也不纳入本次调色。

## 4. 可访问性与阅读约束

- 高饱和度主要落在环境光、按钮、选中面、文件夹和卡片外壳；正文文字保持深色。
- 暖白阅读面上的正文、辅助文字和按钮必须继续满足现有可访问性对比要求。
- 黄色表面使用 `#765400` 或更深文字，不使用白字。
- 明亮薰衣草大面积表面使用深紫或深绿文字；`#b7a8d4` 不承担白字按钮背景。
- 焦点环必须在绿色、黄色、紫色和暖白背景上都清晰可见。
- 不新增持续动画；现有 reduced-motion 合同不变。

## 6. 验证与完成标准

1. 冻结的卡片行为源文件哈希、卡签几何和 `480ms / 440ms` 时序测试继续通过。
2. 色彩合同测试覆盖 C4 工作台令牌、环境渐变、向日葵题目卡和明亮薰衣草知识卡。
3. `npm.cmd run lint`、`npm.cmd run typecheck`、`npm.cmd test` 和 `npm.cmd run build` 全部通过。
4. 浏览器检查 `1440 × 900`、`1024 × 768`、`768 × 900`、`390 × 844`、`375 × 812`，页面不得横向溢出。
5. 真实检查右缘收纳、自然滑出、原路归位、正反翻面、焦点进入/恢复；交互证据与调色前一致。
6. 单独检查题目卡正反面、薰衣草知识卡正反面和手机卡片抽屉，确保文字对比与滚动完整。
7. 最终视觉应明显比当前基线更亮、更饱和；绿色和黄色有活力，紫色通透明亮但不艳丽，中央正文仍然最易阅读。
