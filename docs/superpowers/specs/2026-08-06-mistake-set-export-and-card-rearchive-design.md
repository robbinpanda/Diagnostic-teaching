# 错题集导出、知识库工作区与卡片重新归档设计

日期：2026-08-06

状态：用户已授权直接实施

目标分支：`codex/mistake-library-workspace`

## 1. 目标与边界

本次调整继续使用现有「专注光场 · 明亮中庭」视觉，不新建浏览器路由，不改变六类教学 action、流式生成、会话恢复和幂等合同。根工作台新增三种中央资料浏览状态：错题合集、错题集、知识库；会话答疑和右侧完整卡片管理继续存在。

用户已明确要求不再逐项确认，因此以下解释直接作为实施决策：

- “历史搜题”只是历史会话树的分组标题，不具有跳转行为；只有试卷和题目节点可点击。
- “错题库”只是父级分组标题，下级固定为“错题合集”和“错题集”。
- “打印”先把当前选择保存成错题集，再打开系统打印；“仅保存”只保存并返回错题集列表。
- 错题集保存题目快照，源会话或试卷以后删除时，既有错题集仍能打开和打印。
- 错题集默认名称为带日期时间的“错题集”，打印预览中允许修改名称。
- 知识库按受管试卷归档目录分组；已失去 `exam_papers` 行但仍保留卡片的归档目录继续显示。

## 2. 方案选择

采用“SQLite 错题集快照 + 根工作台中央预览”的方案。

其他方案不采用：

1. 只保存 session ID：实现简单，但删除会话后错题集失效，与长期复习用途冲突。
2. 只存浏览器 localStorage：无法成为 SQLite 可恢复业务态，也不适合跨窗口和数据库迁移。
3. 直接保存二进制 PDF：会复制一套难以演进的生成链路，且现有浏览器打印已经能够打印或另存 PDF。

快照方案保存集合名称、顺序、来源试卷名、题目文本和题图 data URL；页面渲染仍复用 MathText、现有打印样式与 `window.print()`。

## 3. 信息架构

左侧顺序保持：

1. 开始答疑。
2. 历史搜题：不可点击的分组标题、展开按钮、搜索框和“试卷 → 会话”快速树。
3. 知识库：进入中央知识库总览。
4. 错题库：不可跳转的父级分组标题；下设“错题合集”和“错题集”。

中央工作区：

- 错题合集：现有试卷总览和试卷题目页，新增多选模式、跨卷选择状态和导出入口。
- 错题集：总览沿用错题合集纸张封面网格；卡片显示集合名称、题目摘要、题数和保存时间。点击进入可打印的 PDF 预览，不显示可跳转的 session 行。
- 知识库：总览沿用纸张封面网格，按“按试卷归档”下的试卷目录分组；详情显示该卷的知识点卡片，点击卡片仍以现有自然衔接动效打开。
- 右侧卡片栏：保留文件夹、复制、剪切、移动、删除、导出和全部卡片管理，但不再由“知识库/错题集”主导航直接打开。

## 4. 跨卷多选与导出

错题合集总览头部提供“多选”和“导出”按钮。进入多选后：

- 选择状态由根页面持有，不随“总览 ↔ 单卷详情”切换丢失。
- 总览每份试卷可“选择整卷/取消整卷”，并显示已选数量。
- 单卷详情每道题显示复选框；返回总览后可继续进入另一份试卷选择。
- 顶部持续显示已选题数；退出多选会清空选择。
- 导出按钮仅在至少选择一道题时可用，并按用户选择顺序生成预览。

打印预览使用 A4 纵向、暖白纸面和现有 MathText。每道题显示序号、来源试卷、文本与题图。预览提供名称输入、返回选择、“仅保存”和“保存并打印”。保存失败保留预览与选择并显示错误；打印在持久化成功后等待字体与两帧布局稳定，再调用 `window.print()`。

## 5. 错题集数据模型与 API

新增迁移 `0014_mistake_sets`：

- `mistake_sets(id, name, created_at, updated_at)`。
- `mistake_set_items(id, mistake_set_id, source_session_id, source_paper_name, title, problem_text, problem_image_data_url, position, created_at)`。
- `source_session_id` 允许为空，外键使用 `ON DELETE SET NULL`；集合删除不在本次范围。
- `(mistake_set_id, position)` 唯一，保证 PDF 顺序稳定。

API：

- `GET /api/mistake-sets`：返回按更新时间倒序的集合及完整题目快照。
- `POST /api/mistake-sets`：接收名称和有序 session ID；在一个事务内验证、快照并创建集合。
- `GET /api/mistake-sets/{id}`：返回单个集合；不存在时 404。

集合名称去除首尾空白，长度为 1–80；选择为空或含重复 session ID 返回 400；任一 session 不存在返回 404，不能部分保存。

## 6. 知识库与重新归档

知识库只展示 `saved_at` 非空、类型为 `knowledge_card` 的卡片。分组优先依据 `folder.managed_kind === "paper_archive"`；其他知识卡进入“其他知识卡”组。详情显示知识点标题、关键关系和保存时间，点击打开完整卡片。

未收纳和已收纳的知识卡/题目卡都可以选择保存位置：

- pending 卡在闪卡窗口内直接显示试卷文件夹选择器。
- 已归档卡打开后也显示位置选择器；保存知识卡时同时更新内容与位置，题目卡可单独更新位置。
- 右侧“移动卡片”弹窗继续可用。
- 以上入口都提供“新建试卷文件夹”，调用现有 `POST /api/exam-papers`，由后端创建或复用同名受管归档目录；刷新试卷和卡片目录后自动选中新目录。
- 新建同名试卷继续复用既有受管目录和历史卡片。

## 7. 整卡拖拽

移除左上角独立拖动按钮，恢复卡片标题中的灰色圆点。`> 900px` 时整张卡片的非交互表面均可开始拖拽；按钮、输入框、选择框、文本域、链接与可编辑区保持原操作。

拖动仍使用 pointer capture、requestAnimationFrame、内外两层 transform、消息视口边界和 12px 内边距。根卡片本身可聚焦，方向键移动 16px、Shift + 方向键移动 4px、Home 复位；打开时焦点进入卡片窗口，关闭后回到来源。`≤ 900px` 关闭自由拖动，保留流式安全位置。正文不恢复避让。

## 8. 状态、并发与错误

- 所有列表请求使用请求代次，旧响应不能覆盖新保存/移动结果。
- 保存错题集期间禁用重复提交；成功后立即把返回集合写入列表。
- 创建试卷文件夹失败时保留当前卡片和已选目录。
- 已归档卡内容更新成功但移动失败时，用服务端返回的最新卡片刷新本地，再显示移动错误；不伪造原位置。
- 删除源会话只会把错题集条目的 `source_session_id` 置空，快照和 PDF 不变。
- 空知识库、空错题集、加载失败、无搜索结果和已删除来源都提供明确文案。

## 9. 验收

- 历史搜题标题无跳转，快速树仍可搜索、展开、打开和删除会话。
- 错题库下只显示错题合集、错题集；知识库、错题合集、错题集各自拥有唯一中央高亮。
- 可跨至少两份试卷选择题目，保存后在错题集总览出现，打开后内容和顺序一致，删除源会话后仍可打开。
- 打印与仅保存分支均可用，打印样式与现有学习卡片打印视觉一致。
- 知识库按试卷目录分组并可打开知识点。
- pending/archived、知识/题目四种卡片均可重新选择归档目录并新建试卷文件夹。
- 宽屏从整卡表面拖动，灰色圆点可见且无独立拖动按钮；901px 可拖、900px 不拖，键盘和 reduced motion 合同成立。
- 后端 pytest、Ruff，前端测试、ESLint、TypeScript、生产构建及多尺寸浏览器验证通过。
