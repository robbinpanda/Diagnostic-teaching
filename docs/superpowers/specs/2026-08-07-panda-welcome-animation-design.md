# 熊猫欢迎页动画设计规格

## 目标与范围

为尚未开始答疑时的欢迎区域制作一份独立动画预览。视觉与用户提供的参考图保持一致：左侧是标题和两行说明，右侧是坐在书本上的熊猫；背景为平涂米白色，并加入克制的半调圆点与纸张纹理。

本轮只更新独立预览文件，不修改 `apps/web`、原始 `C:\AI4EDU\主页svg\panda.svg` 或其他现有页面代码。预览确认后再单独讨论正式接入。

## 视觉设计

- 采用接近参考图的横向双栏构图，内容整体位于首屏上半部。
- 左侧标题为“今天你想要解决什么问题？”，说明为“上传题目图片，熊猫会帮你理清当时错误思路，陪你梳理\n真实思考逻辑顺序！”。
- 标题使用本地字体文件 `AiDianPaiPaiShua-2.ttf` 的实际字体族“爱点排排刷 / Aidian Paipaishua”，并提供系统黑体回退。
- 背景使用单一米白色，不使用 CSS 或 SVG 渐变。
- 半调效果由 SVG 圆点图案构成，集中在画面边缘和角落，避免干扰正文。
- 纸张纹理使用低透明度 SVG `feTurbulence` 噪声层，保持可读性。
- 删除当前预览中的示例问题、输入框、卡片和大面积装饰光晕。
- 移动端改为文字在上、熊猫在下，保持文字字号和触控区域可读。

## 动画架构

角色动画与文字动画严格分离：

- 熊猫、书本、阴影和身体部件使用 SVG 变换与持续的 `requestAnimationFrame` 驱动，不由 GSAP 控制。
- GSAP 只控制标题字符和说明文字的出现、标题悬停反馈。
- 所有角色路径只渲染一次，通过语义分组施加位移、旋转和缩放；原始路径几何不被改写。
- 动画遵守 `prefers-reduced-motion`：减少动态时直接显示最终状态，仅保留必要的低幅度反馈。

## 入场时间线

### 1. 书本落下（0–0.7 秒）

- 书本从画面上方约 120–160px 处落下。
- 第一次接触时短暂纵向压缩、横向展开，随后完成两次快速衰减回弹。
- 书本阴影在接触瞬间缩小并加深，弹起时扩大并变浅，以强化高度感。
- 使用自定义弹簧积分或等效阻尼曲线，不使用匀速或单段 `bounce` 关键帧。

### 2. 熊猫落下（约 0.55–1.55 秒）

- 书本基本稳定后，熊猫从上方落到书本上。
- 身体首次接触时产生明显但克制的挤压与伸展，然后经过两次衰减回弹恢复。
- 头部、耳朵、手臂和后腿不与身体完全同步，而是继承身体运动后再叠加局部弹簧惯性。
- 耳朵的延迟和回摆最明显，手臂次之，头部最克制；所有部件最终无跳变地回到原位。
- 角色整体落地锚点位于书本接触面中央，避免绕画布中心旋转。

### 3. 文字出现（约 0.65–2.8 秒）

- 标题在书本落下后开始逐字出现，不等待熊猫完全落稳。
- 每个字符间隔约 90–110ms，从下方 14–20px 处缓慢上浮，同时由透明、轻微模糊过渡到清晰。
- 每个字符带极小角度回正，不使用大幅旋转或弹跳。
- 标题完成后，说明文字按行依次淡入并上移，整体节奏比当前预览更慢。
- 鼠标经过标题时只产生低幅度字符浮动，不能破坏排版基线。

## 待机与鼠标追踪

- 熊猫落地完成后进入持续但微弱的呼吸、头部起伏和随机眨眼。
- 鼠标追踪仅在入场完成后启用，作用范围是整个欢迎区域。
- 眼睛追踪幅度大于头部；头部只进行小角度转动和少量平移。
- 鼠标离开后使用阻尼插值缓慢回正，不能瞬间归零。
- 待机动画保持一个持续循环，通过幅度控制与追踪组合，不反复创建或销毁时间线。

## 交互与状态

- “重新播放”仅作为预览控制保留，可重新开始书本、熊猫和文字入场。
- 重播前取消当前入场状态并清理临时速度，但不重复创建 SVG 节点。
- 重播过程中暂停鼠标追踪，落地结束后重新启用。
- 页面失去焦点或不可见时，逐帧循环降低工作量；恢复后不补算长时间差值。

## 验收标准

- 书本必须先于熊猫落下，二者接触和回弹顺序清晰。
- 耳朵等局部部件能够看出惯性，但不能脱离头部或发生路径错位。
- 熊猫角色动画中不存在 GSAP 目标；GSAP 只命中文字内容。
- 标题字体能够正确加载“爱点排排刷”，加载失败时仍有可接受的中文粗体回退。
- 背景没有任何渐变声明，半调与纹理不会降低文字对比度。
- 736px、1024px 和 360px 宽度下无裁切、重叠或横向滚动。
- 开启减少动态效果时，内容立即可读且页面功能不受影响。
- 原始 SVG 哈希和 `apps/web` 工作区保持不变。
