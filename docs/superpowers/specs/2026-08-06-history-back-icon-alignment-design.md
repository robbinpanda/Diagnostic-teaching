# 历史搜题详情返回与对话导航设计

> **后续规格说明（2026-08-06）：** [`2026-08-06-mistake-library-workspace-design.md`](./2026-08-06-mistake-library-workspace-design.md) 保留本文的纯图标返回按钮和对齐规则，但把中央页面迁为“错题合集”，并规定从合集题目进入原会话后导航归属“历史搜题”。下文用删除线标出的“开始答疑”高亮规则已失效。

## 背景

历史搜题的试卷详情页目前使用“左箭头 + 返回全部试卷”文字按钮。用户希望将它精简为纯图标，并让图标按钮的左边缘与下方题目卡片左边缘对齐。

当前从历史试卷中打开某道题目时，中央区域会恢复原答疑会话，但左侧仍高亮“历史搜题”。~~用户希望复用现有答疑页面，并将主导航高亮切回“开始答疑”。~~ 后续确认改为历史会话继续归属“历史搜题”；历史试卷树保持原展开状态。

## 已确认方案

采用方案 A：保留现有返回行为，将详情页返回按钮改为 `44 × 44px` 的纯左箭头按钮。视觉上不显示文字，但继续提供 `aria-label="返回全部试卷"` 和同义 `title`，保证键盘、读屏和悬停提示可用。

详情页头部使用比题目内容区多出左右内边距的最大宽度。宽屏下，头部容器的内侧起点与 `1120px` 题目内容区的外侧起点重合；窄屏下，头部和内容区继续共享现有响应式内边距。因此，最左侧可见头部控件与题目卡片在各断点保持同一条垂直基线。

## 组件与样式

- `HistoryWorkspace.tsx`
  - 详情页返回按钮只渲染 `ArrowLeft`。
  - 添加稳定的 `aria-label` 和 `title`。
  - 为详情页头部添加专用修饰类，避免改变历史总览页布局。
- `history.css`
  - 返回按钮固定为 `44 × 44px`，去除文字按钮的横向 padding。
  - 详情页头部最大宽度补偿现有左右 `32px` 内边距，使按钮与题目内容区对齐。
- `responsive.css`
  - 沿用现有 `16px`/`12px` 小屏内边距；不新增负边距或绝对定位。
- `page.tsx`
  - ~~`handleOpenHistorySession` 在离开历史工作区时将 `activeNavigation` 设为 `"start"`。~~ 现行行为先清空错题合集视图，再以“历史搜题”归属调用既有打开会话链路。
  - `handleOpenSession` 不自行覆盖调用方已经确定的中央导航归属；刷新恢复历史 session 同样归属“历史搜题”。
  - 不调用 `handleStartNewChat`，因此不会创建新页面、清空当前会话或新建答疑。
- `SessionSidebar.tsx`
  - 无需修改；其本地 `historyExpanded` 与 `expandedPaperIds` 状态继续保留，历史试卷树不会自动收起。

## 行为与边界

- 点击、键盘激活与原有 `onBackToOverview` 行为保持不变。
- 左侧会话栏关闭时，展开会话栏按钮仍是头部最左侧控件；返回图标排在其后，避免控件重叠。
- ~~点击历史题目后“开始答疑”进入激活态，“历史搜题”不再高亮。~~ 现行导航高亮“历史搜题”，快速树继续标记该 session；只有新建答疑归属“开始答疑”。
- 历史试卷树的展开状态保持不变；用户仍可直接查看和选择其他历史题目。
- “开始答疑”按钮原有的显式点击行为保持不变：用户主动点击它时仍开始新答疑。
- 不修改历史搜索、排序、详情筛选、删除、会话恢复和学习卡片行为。
