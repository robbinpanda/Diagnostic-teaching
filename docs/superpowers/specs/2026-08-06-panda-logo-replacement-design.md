# 熊猫析题左上角 Logo 替换设计

## 背景

前端左上角当前由一个内联绘制的简化熊猫图形和“熊猫析题”文字组成。品牌目录 `C:\AI4EDU\ui lowpoly` 中已有正式的熊猫阅读 SVG，需要用它替换现有图形，同时保留文字。

## 已确认方案

将 `panda-app-logo-editable-smooth.svg` 原样复制为前端公共品牌资源 `apps/web/public/branding/panda-app-logo.svg`。`PandaMark` 保留现有 `size` 接口，但内部改用 Next.js `Image` 引用该静态资源。

## 视觉与可访问性

- 桌面端继续使用 `36 × 36px`，移动端继续由现有响应式样式缩放为 `31 × 31px`。
- 保留右侧“熊猫析题”文字、顶栏间距与布局。
- Logo 图形在已有品牌容器中作为装饰图片处理；容器继续提供 `aria-label="熊猫析题"`。
- 不修改 SVG 的白色圆角底、黑色熊猫图形或透明外部区域。

## 边界

- 不引入 SVG loader 或新的依赖。
- 不修改其他图标、页面元数据、业务行为或响应式断点。
- 不覆盖当前工作区中与本任务无关的未提交改动。

## 验证

- 检查公共 SVG 与来源文件完全一致。
- 运行前端 TypeScript 检查与相关组件测试。
- 检查 Git 差异只包含品牌资源、顶栏引用和本任务说明。
