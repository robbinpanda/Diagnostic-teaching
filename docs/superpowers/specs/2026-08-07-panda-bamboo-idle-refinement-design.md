# 熊猫欢迎页竹子与待机动画增量规格

## 范围

本规格只调整独立欢迎页动画预览，不修改 `apps/web`、`C:\AI4EDU\主页svg\panda.svg` 或 `C:\AI4EDU\主页svg\bamboo.svg`。它继承既有书本先落、熊猫后落、文字逐字出现、平涂米白背景和鼠标追踪设计。

## 熊猫显现与待机

- 熊猫在页面初始渲染和书本落下期间完全不可见，不能出现首帧闪烁。
- 到熊猫落下开始时间 `550ms` 的前一帧才解除隐藏并进入落下动画。
- `prefers-reduced-motion` 下熊猫直接显示最终静止状态。
- 熊猫落地后的待机由三个低幅动作合成：脚底锚点左右摇晃、纵向呼吸缩放、上下弹动。
- 呼吸缩放约为 `1.0–1.012`，上下弹动约 `2–3px`，左右摇晃不得盖过鼠标追踪。
- 所有待机、落地、眨眼和追踪继续在同一个持久 `requestAnimationFrame` 循环内组合。

## 三株竹子

- 原始 `bamboo.svg` 的画布为 `241×475`，包含三节竹竿和两片叶子，没有语义 ID。
- 在预览副本中为竹节和两片叶子补充分组；原始文件保持不变。
- 使用同一份几何生成三株视觉实例：左侧一株最大，标题下方放置两株较小且角度不同的竹子。
- 三株竹子保持原始淡绿色；通过平移、缩放、水平镜像或旋转形成差异，不能重新绘制造型。
- 竹子与标题同时开始出现，三株之间依次错开 `0.12s`。
- 竹子入场可以由 GSAP 控制透明度、位移和缩放；持续待机不能由 GSAP 循环控制。
- 每株竹竿使用不同相位自然左右摇晃，幅度约 `1.5–2.5°`；两片叶子在连接点附近以 `4–7°` 的更大幅度叠加摆动。
- 三株竹子的摆动必须合并进现有持久逐帧循环，并遵守减少动态设置。

## 文字排版

- 主标题“今天你想要解决什么问题？”在所有支持宽度下保持一行，不允许自动换行。
- 标题通过 `clamp()` 与窄屏专用字号缩放适配，不能依靠裁切或横向滚动。
- 内文拆分为三个不可内部换行的语义短句：
  1. `上传题目图片，`
  2. `熊猫会帮你理清当时错误思路，`
  3. `陪你梳理真实思考逻辑顺序！`
- 页面只在两个逗号之后提供换行机会，短句内部不能断行。
- 本地字体兼容性可以在正式接入产品浏览器时继续调整，本轮保留当前字体声明和中文粗体回退。

## 验收

- 初始时熊猫不可见，书本开始落下；`550ms` 到达时熊猫出现并开始落下。
- 待机时能同时看出呼吸、轻微上下弹动和左右摇晃。
- 页面上正好出现三株由 `bamboo.svg` 变形得到的竹子，叶子摆幅大于竹竿。
- 竹子和文字同步开始入场，竹子实例间隔为 `0.12s`。
- 标题始终单行，内文只可能在逗号后换行。
- 角色与竹子持续动画不使用 GSAP 循环。
- 原始两个 SVG 哈希不变，`apps/web` 无变化，既有静态验证继续通过。
